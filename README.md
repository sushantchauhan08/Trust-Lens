# Trust Lens 🔍

### Verify Before You Trust. Shop With Confidence.

Trust Lens is an AI-powered product trust and authenticity assistant designed to help users make more informed purchasing decisions. It aims to help users evaluate product credibility, identify potential warning signs, and make safer choices before buying online.

In an online marketplace filled with countless products, sellers, and claims, knowing what to trust can be difficult. Trust Lens aims to make that decision easier by bringing product evaluation and AI-assisted insights into one place.

## ✨ Project Overview

**Trust Lens** explores how artificial intelligence can help consumers assess product trustworthiness before making a purchase.

The goal is simple: help users pause, evaluate available information, and make more informed buying decisions instead of relying solely on marketing claims.

## 🎯 Key Objectives

- Help users evaluate product credibility before purchasing.
- Explore AI-assisted product analysis and trust assessment.
- Highlight potential warning signs that deserve further investigation.
- Support more informed and confident shopping decisions.
- Demonstrate the practical application of AI in consumer-focused applications.

## 🚀 Features

The project is intended to support a product trust evaluation experience, with capabilities depending on the current implementation:

- **Product Trust Assessment** — Help users evaluate whether a product appears trustworthy.
- **AI-Assisted Analysis** — Explore the use of AI to interpret product information.
- **Risk Awareness** — Help users identify potential concerns before purchasing.
- **Decision Support** — Present useful information to support more informed shopping choices.
- **Consumer-Focused Experience** — Keep product evaluation accessible and easy to understand.

> Note: These describe the project's intended goals. The availability and accuracy of individual features depend on the implemented application.

## ⚙️ Getting Started

### Prerequisites

- Git
- Android Studio with a compatible Android SDK
- A compatible JDK
- A Google Gemini API key if required by the implemented AI features

### Clone the Repository

```bash
git clone https://github.com/sushantchauhan08/Trust-Lens.git
cd Trust-Lens
```

### Open the Project

1. Open Android Studio.
2. Select **Open** and choose the cloned `Trust-Lens` directory.
3. Allow Gradle to sync the project.
4. Configure any required API credentials securely.
5. Run the application on a compatible emulator or Android device.

**Important:** Verify the actual application module and run configuration in Android Studio before running the project.

## 🔐 API Key Security

Trust Lens uses a Gemini API key placeholder in its `.env.example` configuration.

- Never commit a real API key, password, or other secret to GitHub.
- Configure secrets through the appropriate development environment.
- Do not expose privileged API credentials in a publicly distributed client application.
- Review API restrictions and usage limits before deploying the application.
